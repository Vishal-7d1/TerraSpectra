# 03. Exploratory Data Analysis (EDA)

## Purpose
This folder contains scripts and visual analytics to explore spectral signatures, band correlations, and disease-induced bio-optical shifts.

## Contents
- `eda.py`: Performs statistical exploratory data analysis, class balance evaluations, and distribution inspections across spectral bands.
- `spectral_analysis.py`: Computes and plots mean spectral reflectance profiles (Healthy vs. Diseased), calculates first and second spectral derivatives, and analyzes the "Red-Edge" inflection shift (690nm–740nm).
- `outputs/`: Destination folder for generated exploratory plots, spectral signature graphs, and statistical summary reports.
