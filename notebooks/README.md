# Notebooks Directory

This folder contains experimental workflows and exploratory data analysis:

- `01_eda_spectral_signatures.py` (or `.ipynb`): Spectral curve inspection, outlier detection, and healthy vs. diseased band distribution.
- `02_preprocessing_and_indices.py` (or `.ipynb`): Savitzky-Golay smoothing, SNV calibration, and Narrow-band index calculations (NDRE, PRI, NDVI).
- `03_model_prototyping.py` (or `.ipynb`): Model benchmarking with Random Forest, SVM, and XGBoost.
